MCP: letting an AI assistant call your server

In one sentence

MCP (Model Context Protocol) is JSON-RPC 2.0 over stdin/stdout; an AI client like Claude Desktop launches your binary and calls its 'tools'.

Why it exists

The dashboard is for humans. MCP is the dashboard for AI assistants: you ask Claude 'which model handled the most traffic today?' and it calls get_stats on your server and answers from real numbers.

How it works in this project

The whole server is ~200 lines of stdlib in mcp/server.go. Three methods matter:

client → {"jsonrpc":"2.0","id":1,"method":"initialize","params":{...}}
server → {"jsonrpc":"2.0","id":1,"result":{"protocolVersion":"2024-11-05",
           "capabilities":{"tools":{}},"serverInfo":{"name":"agentops","version":"0.1.0"}}}

client → {"jsonrpc":"2.0","id":2,"method":"tools/list"}
server → {"jsonrpc":"2.0","id":2,"result":{"tools":[{name, description, inputSchema}, ...]}}

client → {"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"get_stats","arguments":{}}}
server → {"jsonrpc":"2.0","id":3,"result":{"content":[{"type":"text","text":"{...json...}"}]}}

The loop: read one line from stdin → unmarshal → handle() → write one line to stdout. Notifications (no id) get no reply. A malformed line gets JSON-RPC error -32700 instead of being silently dropped (deep-review fix #14).

Try it yourself

echo '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | go run . --mcp

Interview questions

Q What is MCP in one sentence?
A A standard way for an AI client to discover and call tools on a server, using JSON-RPC over stdio or HTTP.
Q Why stdio?
A Claude Desktop launches the binary as a child process and talks over its pipes. No ports, no auth, no network — perfect for a local tool.
Q Why write it by hand instead of using an MCP SDK?
A The protocol surface I need is three methods. The stdlib JSON encoder and a line scanner cover it, and I can explain every byte on the wire.

Remember

  • MCP = JSON-RPC 2.0 over stdio.
  • initialize → tools/list → tools/call.
  • One line in, one line out; notifications get no reply.
