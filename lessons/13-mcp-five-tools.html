The five MCP tools

In one sentence

list_models, get_stats, route_test_request, inspect_trace, get_drift_report — each one is a thin wrapper over something the router already does.

Why it exists

A tool should not contain logic. It should expose logic that exists and is tested elsewhere. That's why the MCP server takes a *router.Server and two lookup functions, and nothing else.

How it works in this project

// mcp/server.go — the shape of every tool
{ Name: "route_test_request",
  Description: "Send one prompt through the router and see which model handled it and why.",
  InputSchema: {"type":"object","properties":{"prompt":{"type":"string"}},"required":["prompt"]} }

case "route_test_request":
    prompt, _ := args["prompt"].(string)
    if prompt == "" { return nil, &rpcError{Code: -32602, Message: "prompt is required"} }
    out, err := s.Router.Chat(prompt, 0)          // SAME path as HTTP → same counters, same spans
    ...
case "inspect_trace":
    data, err := s.TraceLookup(traceID)           // injected from main.go (needs Postgres)
    if errors.Is(err, tracker.ErrTraceNotFound) {
        return nil, &rpcError{Code: -32004, Message: fmt.Sprintf("trace %q not found", traceID)}
    }

Error codes follow JSON-RPC conventions: -32601 unknown method/tool, -32602 bad params, -32000 server error (backend down), -32004 not found, -32700 parse error.

Try it yourself

printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_models","arguments":{}}}' | go run . --mcp

Interview questions

Q Why does route_test_request affect get_stats?
A Because it calls the same Router.Chat the HTTP handler calls. If MCP had its own path, the stats would lie.
Q How does the MCP server read traces without importing Postgres?
A Dependency injection: main.go sets mcpSrv.TraceLookup = func(id) { return queryTrace(pool, id) }. The mcp package only knows 'a function that returns data or an error'.
Q What's the input schema for?
A The AI client reads it to know which arguments to send. It's JSON Schema; required tells Claude it must supply a prompt.

Remember

  • Tools wrap existing, tested logic.
  • Shared Chat() path keeps stats honest.
  • JSON-RPC error codes, not HTTP codes.
