Try+Live cockpit — 20 full pages

Should #/try (send a prompt) and #/live (watch spans land) become one interface? This report says yes, as a cockpit: send and sight on one surface, one SSE connection, one mental model — type → ticket appears → stages land → answer pops. Twenty full-page compositions below, gamified and simple, each a whole cockpit in a different arrangement. Aesthetic: industrial-utilitarian with a playful whisper; DFII 15 (4+5+4+4−2). Anchor: your ticket — the send becomes a pinned, amber-bordered quest ticket at rail top. Game lens: the 30-second core loop is now complete (action→feedback→reward→repeat) with achiever/explorer mechanics on fixed schedules. Traced chain: pageTry() tryPromise/lastTry + pageLive() tickets/SSE (console/static/app.js) share POST /v1/chat/completions, GET /v1/events, and the span store — merging is composition, not plumbing.
