The corpus cleaner: chunking and dedup

In one sentence

A 90-line Python script turns markdown docs into clean, overlapping, de-duplicated chunks — and running it twice gives the same result.

Why it exists

Garbage in, garbage out. Markdown symbols, code fences and duplicate paragraphs would pollute embeddings. And an ingest script that isn't idempotent creates duplicate rows every time you run it.

Try it yourself

Run python scripts/clean_docs.py twice. The second run prints the same chunk count and the output files are byte-identical — that is what idempotent means.

Interview questions

Q Why 900/120 and not 2000/500?
A A previous project used 2000/500 for huge French PDFs. These docs are 2–4 paragraphs; 900 keeps one idea per chunk. Overlap avoids losing a sentence that straddles a boundary.
Q Why hash the content?
A Two reasons: skip exact duplicates, and give each chunk a stable identity so re-runs update in place instead of inserting again.
Q Why Python here when everything else is Go?
A Text cleanup with regexes is a 10-minute Python job. It runs once offline and writes plain JSONL that Go reads. Right tool, small blast radius.

Remember

  • normalize → chunk → dedup by hash.
  • 900 chars, 120 overlap, min 200.
  • Idempotent: run twice, same output.
