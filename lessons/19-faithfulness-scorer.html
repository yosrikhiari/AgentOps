Part 4 · The fact-checker (RAG + evals)

The faithfulness scorer: split claims, judge each one

In one sentence

Faithfulness = the fraction of an answer's sentences that a judge model says are supported by the retrieved text.

Why it exists

'Is this answer true?' is too vague to score. 'Is each sentence supported by the sources?' is concrete. That's the RAGAS/DeepEval definition, implemented by hand in ~100 lines.

How it works in this project

// evals/scorer.go
claims := SplitClaims(p.Answer)                 // split on . ! ? followed by space; keep ≥10 runes
for _, cl := range claims {
    ok, just, err := judge.JudgeClaim(ctx, cl, contextText)   // one LLM call per claim
    if ok { supported++ }
}
res.Faithfulness = float64(supported) / float64(len(claims))  // 0.0 … 1.0

// evals/judge.go — the prompt the judge sees
Decide if the CLAIM is fully supported by the CONTEXT. Ignore answer length and style.
First write 1-2 sentences of evidence-based justification quoting the context.
Then on the last line write exactly: VERDICT: SUPPORTED or VERDICT: REFUTED.

Flow for one golden pair: embed the question → fetch top-5 chunks → join them as CONTEXT → split the golden answer into claims → ask the judge about each claim → average.

Live result on a 6-pair subset: correct answers scored 1.00, deliberately false answers scored 0.00 — the scorer discriminates, which is the first thing to prove about any metric. Full frozen-v1 run (32 pairs, judge qwen3:8b): 0.969 on two consecutive runs (31 of 32 at 1.00, recall 1.000, drift delta 0). The one miss each time was a list-fragment answer with no verb — a golden-authoring lesson, recorded for v2.

Interview questions

Q What is faithfulness, precisely?
A supported claims ÷ total claims, where a claim is one sentence of the answer and 'supported' is a judge model's verdict given only the retrieved chunks.
Q Why one judge call per claim instead of one per answer?
A A single 'is this answer OK?' call lets one bad sentence hide behind three good ones. Per-claim gives a real fraction and tells you which sentence failed.
Q How did you prove the scorer works?
A Scored known-good answers (1.00), then corrupted the same answers with false claims (0.00). If a metric can't tell those apart, it's noise.

Remember

  • Split answer into claims, judge each, average.
  • Judge sees only retrieved chunks.
  • Prove a metric discriminates before trusting it.
