Principles

01 · Operator first
Answer "is it healthy?" in one glance
status dot, pills and the strip carry state; text explains it.
02 · One accent
Amber means "the thing to look at"
active nav, primary action, quality-tier bars, selected trace. Nothing else is amber.
03 · No framework
Hand-written CSS, h() helper
~255 lines of CSS, zero dependencies, embedded in the Go binary.
04 · Every state designed
loading · empty · error · live
a page is not done until all four render.

Tokens

Everything is a --tower-* custom property on :root. Three neutrals stacked (ground → surface → raised), three inks, one accent, two status hues, each with a -dim partner for backgrounds.

How to extend

Adding a component
  1. Prefix the class tower-; put it in the matching /* ===== */ block of console/static/tower.css.
  2. Only tokens. A new hex is a new token with a name and a reason.
  3. Build it with h(tag, attrs, ...children). Children are text or nodes — there is no html: attribute and no innerHTML anywhere.
  4. Design loading, empty and error before live. Reuse skeleton(), errorBox(), .tower-empty.
  5. Numbers that change are .tower-mono. Ids link to #/traces/<id>.
  6. State → pill. Fact → chip. Never colour a chip.
  7. Add the example to this page and cite where it's used.
The h() helper (console/static/app.js)
function h(tag, attrs, ...children) { const el = document.createElement(tag); if (attrs) for (const [k, v] of Object.entries(attrs)) { if (k === 'class') el.className = v; else if (k === 'onclick') el.addEventListener('click', v); else if (v !== null && v !== undefined) el.setAttribute(k, v); } for (const c of children.flat()) { if (c === null || c === undefined) continue; el.append(c instanceof Node ? c : document.createTextNode(String(c))); } return el; } // page contract: every page is // async function pageX(signal, sub) // and owns skeleton → fetch → replaceChildren, // aborting on navigation, polling only while live.
